# 꿀픽 ADMIN (운영 콘솔)

WBS 담당: 김호진

이 브랜치(`part/김호진-web`)에는 꿀픽 온라인의 정적 관리자 콘솔(`apps/web`)이 구현되어 있습니다. 팀 FastAPI 백엔드 서버의 회원·카탈로그·고객센터 PostgreSQL DB와 실시간으로 연동되어 제휴상품, 상품 크롤링 검토, 고객상담, 통계, 고객정보, 관리자 가입 승인을 관리합니다.

## 1. 실행 및 서버 연결

저장소 루트에서 아래 명령으로 어드민 웹 서버를 실행하고 `http://localhost:3000`에 접속합니다.

```sh
node apps/web/local-demo.cjs --api
```

- **백엔드 API 주소**: `apps/web/index.html`의 `<meta name="api-base" content="/backend" />`는 같은 웹 서버의 Next.js 프록시(`app/backend/[...path]`)를 가리킵니다.
  - 프록시가 요청을 넘길 실제 FastAPI 주소는 웹 서버 환경변수 `INTERNAL_API_URL`(기본 `http://127.0.0.1:8000`)로 정합니다.
  - NAS 서버를 쓸 때는 `INTERNAL_API_URL`에 팀에서 공유한 주소를 넣습니다. 서버 주소·포트는 공개 저장소에 적지 않습니다.
- **CORS 주의사항**: 백엔드의 `DEV_ORIGINS` 설정에 따라 어드민 콘솔은 반드시 `http://localhost:3000` 주소로 접속해야 API 요청이 허용됩니다 (`file://` 직접 열기나 다른 포트 사용 시 CORS 차단).

## 2. 관리자 로그인 및 가입 승인

소병선 담당 FastAPI 서버의 회원 DB와 로그인 세션을 사용하므로 어드민 웹에 별도의 DB 접속 정보를 저장하지 않습니다.

- **권한별 메뉴 접근**:
  - `admin` (관리자): 전체 메뉴(`MAIN`, `상품관리`, `고객상담`, `통계`, `고객정보`, `관리자 가입 승인`) 사용 가능
  - `support` (상담 담당자): `고객상담` 메뉴 전용
- **관리자 가입 신청 및 승인**:
  1. 계정이 없다면 로그인 화면(`#/login`)에서 **관리자 가입 신청**(`#/signup`)을 선택해 신청합니다.
  2. 신청 계정은 승인 전까지 로그인이 제한되며(`"관리자 가입 승인 대기 중입니다."`), 기존 관리자(`admin`) 계정으로 로그인한 뒤 좌측 사이드바의 **관리자 가입 승인**(`#/admin-requests`) 메뉴에서 신청 내역을 확인합니다.
  3. 역할을 `관리자` 또는 `상담 담당자`로 지정해 **승인**하면 신청자가 즉시 로그인할 수 있습니다.
  4. 관리자 가입 신청·승인(`/v2/admin/auth/*`) 및 카탈로그 선택 삭제(`/v2/admin/catalog/offers/delete`)는 모두 팀 백엔드 서버(`member_0004` 적용)를 통해 처리됩니다.
- 가입 화면의 개인정보 수집·이용 동의 문안과 버전(`privacy-2026-11-16`)은 팀 사용자 앱과 동일한 기준을 사용합니다.

## 3. 주요 메뉴 및 기능

- **MAIN · 대시보드 (`#/main`)**
  - 전체 회원, 등록 제휴상품, 카탈로그 수집 상품, 상담 내역 실시간 요약 지표를 표시합니다.
  - 누적 구독자 수, 당일 구독자 수, 당일 해지 인원수, 일자별 구독 가입·해지 추이 차트, 당월/금일 구독 매출을 표시합니다.
  - 우측 독립 패널인 **처리할 일 (`Action`)**에서 **답변 대기 상담**과 **7일 이내 종료되는 제휴상품** 건수를 확인하고 클릭 시 해당 필터 화면으로 즉시 이동합니다.
- **제휴상품 관리 (`#/affiliate`)**
  - 카탈로그 판매정보(`/v2/offers`)를 검색·선택해 상품명, 금액, URL을 자동 입력받고 유효기간과 함께 제휴상품을 등록·수정·비활성화합니다.
  - 외부 쇼핑몰 URL(도매꾹, 11번가 등) 입력 시 서버의 호스트 허용 목록(`AFFILIATE_URL_HOSTS`) 제약이 있더라도 호환 리다이렉트 URL로 자동 변환해 저장하고 화면에는 원본 URL을 표시합니다.
- **상품 크롤링 검토 (`#/crawling`)**
  - 기간 제한 없이 DB에 적재된 전체 카탈로그 상품의 **일자별 상품 수집 현황**(확인 일자, 등록 상품 수)과 **날짜별 그룹핑된 카탈로그 상품 목록**을 조회합니다.
  - 카탈로그 유형(일반/식품), 수집처(도매꾹, 11번가 등), 현재 상태(판매 중/품절/종료/확인 필요), 날짜별 필터 및 검색을 지원합니다.
  - **크롤링 실행** 버튼으로 수집 주기를 기다리지 않고 즉시 1회 수집·DB 재동기화를 실행할 수 있습니다.
  - 목록에서 상품을 체크해 **선택 삭제**할 수 있으며, 제휴상품에 연결된 상품은 자동 보호됩니다.
- **고객상담 (`#/counseling`)**
  - 고객이 사용자 앱/확장에서 남긴 1:1 문의를 조회하고 실시간 답변 전송 및 상담 완료 처리를 수행합니다.
  - 상담 목록 화면에 머무는 동안 5초 주기로 새 문의와 상태 변경을 자동 갱신하며, 우측 고객정보 카드에서 고객의 연령대·성별·구독 여부를 함께 확인합니다.
  - **상담설정**에서 운영 요일, 시작·종료 시간(KST), 부재중 안내 메시지를 서버 DB(`/v2/admin/support/settings`)에 저장합니다.
- **통계 (`#/stats`)**
  - 일별, 월별, 연도별 단위 및 사용자 지정 기간별로 실제 DB 기준의 **구독 가입·해지 추이(명)**와 **매출 추이(만원)** 라인 차트를 제공합니다.
- **고객정보 (`#/customers`)**
  - 최근 활성 회원(최대 100명)의 로그인 아이디, 회원 UUID, 구독 여부(`O`), 성별, 연령대, 계정 상태, 가입 일시(KST)를 조회하고 회원 유형(구독자/미구독자) 및 키워드로 필터링합니다.
  - 아이디 클릭 시 고객 세부정보(구독 시작일자 포함) 화면을 확인할 수 있습니다.

## 4. 백엔드 없이 로컬 데모 모드로 화면 검증

백엔드 연결 없이 로그인/회원가입 흐름만 로컬에서 단독 검증하려면 `--api` 옵션 없이 실행하고 `http://localhost:3001/?demo=1#/signup`을 엽니다.

```sh
node apps/web/local-demo.cjs
```

로컬 데모 계정 파일(`apps/web/.local-demo/accounts.txt`)은 `.gitignore`에 의해 Git 커밋 대상에서 자동 제외됩니다.
