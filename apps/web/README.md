# 사용자 웹

WBS 담당: 김호진

이 브랜치에는 정적 관리자 콘솔이 있습니다. 팀 API 모드는 제휴상품, 활성 회원, 상담, 상품 카탈로그 데이터를 서버에서 읽습니다. 예시 데이터는 로컬 데모에서 볼 수 있습니다.

## 관리자 로그인 및 판매정보 조회

소병선 담당 FastAPI 서버의 기존 회원 PostgreSQL DB와 로그인 세션을 사용합니다. 어드민 웹에는 DB 연결 정보가 필요하지 않습니다. 백엔드 담당자에게 받은 `admin` 또는 `support` 권한의 기존 계정으로 로그인합니다. `admin`은 전체 메뉴, `support`는 고객상담 메뉴를 사용할 수 있습니다.

계정이 없다면 로그인 화면에서 **회원가입**을 선택합니다. 가입은 기존 `POST /v2/auth/signup`을 사용하며 일반 회원으로 생성됩니다. 가입한 아이디를 백엔드 담당자에게 알려 권한 부여를 요청합니다. 가입 화면의 개인정보 동의 문안과 버전은 팀 모바일 앱의 초안을 사용합니다. 팀에서 문안을 변경하면 가입 화면의 문안과 버전도 함께 갱신합니다.

백엔드 API가 실행 중일 때 저장소 루트에서 아래 명령으로 웹을 실행하고 `http://localhost:3000`에 접속합니다.

```sh
node apps/web/local-demo.cjs --api
```

API 주소는 `index.html`의 `api-base`에서 설정합니다. PC에서 FastAPI를 실행하는 경우 기본 주소는 `http://localhost:8000`입니다. 웹 주소를 변경하면 백엔드의 `DEV_ORIGINS`에 웹 origin을 추가합니다. 공유 환경에서는 HTTPS 주소를 사용합니다. [백엔드 실행 안내](https://github.com/daon217/swproject/blob/main/services/api/README.md)

팀 API 모드에서 [고객상담](http://localhost:3000/#/counseling)을 열고 권한이 있는 테스트 계정으로 로그인합니다. 상담 목록에서 대화를 선택하면 최신 메시지를 확인할 수 있습니다. 고객이 보낸 새 메시지는 대화 화면의 **새로고침** 버튼으로 확인합니다.

- **제휴상품**은 판매정보에 연결된 제휴 조건을 조회·등록·수정·비활성화합니다. 서버가 허용한 HTTPS 주소를 제휴 URL로 입력해야 합니다.
- **고객정보**는 최근 활성 회원 최대 100명의 로그인 아이디, UUID, 가입 일시를 표시합니다. 다른 회원의 세부 프로필, 구독 정보 조회와 비밀번호 초기화는 현재 팀 API에서 제공하지 않습니다.
- **상품 크롤링 검토**는 카탈로그의 일반 상품과 식품을 구분해 마지막 확인 시각을 표시합니다. **수집처 → 도매꾹**을 선택하면 팀 DB에 반영된 도매꾹 상품만 조회합니다. 도매꾹 적재는 수집팀의 별도 승인·전송 설정이 필요하며, 일자별 수집 건수는 별도 집계 API가 필요합니다.
- **대시보드**의 답변 대기와 종료 예정 건수는 실제 상담과 제휴상품에서 계산합니다. 전체 구독·매출 집계는 팀 API에 아직 없습니다.

## 백엔드 없이 로그인 화면 검증

저장소 루트에서 `node apps/web/local-demo.cjs`를 실행하고 [로컬 데모 회원가입](http://localhost:3001/?demo=1#/signup)을 엽니다.

가입한 아이디와 비밀번호 검증용 scrypt 해시는 `apps/web/.local-demo/accounts.txt`에 저장됩니다. 이 파일은 웹에서 제공하지 않으며 Git에서도 제외됩니다. 로컬 데모 서버를 다시 시작해도 가입한 계정은 남고, 로그인 세션은 다시 생성해야 합니다.

데모 모드는 `http://localhost:3001/?demo=1`에서만 사용합니다. 앞의 FastAPI 실행 방법으로 접속하면 기존 회원 DB를 사용하는 인증으로 연결됩니다. 판매정보 조회는 별도로 카탈로그 API 연결이 필요합니다.
