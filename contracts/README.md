# 서비스 간 계약

API 요청·응답, 상태·오류 코드, 이벤트 구조와 가상 JSON 예시를 함께 관리합니다.
기준은 기술 명세서 17장이며 원문 경로와 보완안을 구분합니다.
추가할 계약마다 제공 서비스, 소비 서비스, 인증 범위, 버전, 성공·실패 예시를 명시합니다.

| 업무 | 요청·응답 계약 | 현재 범위 |
| --- | --- | --- |
| 수집·상품 갱신·조회 | [catalog-v2](catalog-v2.md) | 실제 DB 수신·중복 제거·필드별 최신화 |
| 회원·프로필·구독·결제 | [member-billing-v2](member-billing-v2.md) | 인증과 모의 결제, 실제 PG 미연결 |
| 고객센터·제휴·관리자·탈퇴·분석 | [independent-backend-v2](independent-backend-v2.md) | 업무 API 및 작업 관리, 실제 OCR/추천 미연결 |

미완성 프론트 참고본을 반영한 임시 계약입니다. 연동 변경은 담당자와 협의합니다. 실제 개인정보·인증값을 예시에 넣지 않습니다.
